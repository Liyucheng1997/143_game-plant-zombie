# 花园防线 · 成长战役

基于 Three.js 的单机塔防游戏：6 个关卡、9 种植物、6 类僵尸，以及可保存的星级与段位成长。保留原有生成素材，新角色使用配色、标记与几何装备区分。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址，点击关卡开始。默认使用更轻松的「休闲」难度，可在关卡地图中切换为「标准」；难度在选择关卡或重开时生效。

## 玩法与平衡

- 休闲第一关从 550 阳光开始，有 25 秒准备时间；标准为 450 阳光和 20 秒。
- 选择卡牌后点击草坪种植，鼠标也支持拖放。手机使用点击选牌、滑动卡牌栏。
- 射手价格降到 75，阳光每 5.5 秒掉落；阳光可点击收集，也会自动回收。击杀敌人另有阳光奖励。
- 每关 2–4 波，敌人数有限，必须清完本波才能继续。波间整备 12 秒并补给 75 阳光。
- 每行有一台一次性割草机。已经消耗割草机的行再次被突破时失败。
- 点击「升级植物」再点击植物可升到 Lv.3，每级伤害 +45%（相对初始伤害）、生命上限 +45%，并回满生命；射击间隔缩短。向日花每级生产速度 +30%。首次费用为植物价格的 60%，第二次为 120%（取到最接近的 5）。樱桃不可升级。
- 「铲除回收」返还该植物累计投入的 50%；「支援轰炸」对指定行所有敌人造成 180 伤害，消耗 50 阳光，冷却 40 秒。
- 空格暂停/继续；Escape 退出工具模式；切到后台时自动暂停。

## 晋级与存档

无割草机消耗获得 3 星，消耗 1–2 台获得 2 星，其余获得 1 星。每星 40 XP，只保存最佳星级，重玩补足差额，不重复发经验。

每 160 XP 晋升一次：见习园丁 → 花园守卫 → 防线专家 → 植物大师 → 花园传奇。每段位增加 25 开局阳光和 5% 伤害，在下一次开始关卡时生效。

通关解锁下一关及新卡牌。关卡、最佳星级和难度存入当前浏览器的 localStorage（`garden-defense-campaign-v1`）。清除浏览器站点数据会清空进度；存储不可用时会提示，并保留当前页面内的进度。

## 验证

```bash
npm test
npm run build
```

浏览器集成测试需要先运行开发服务器，测试默认为 `http://localhost:5173`：

```bash
npx playwright install chromium
npm run test:browser
```

Windows 已安装 Edge 时可直接使用：

```powershell
$env:BROWSER_CHANNEL = 'msedge'
npm run test:browser
```

可通过 `GAME_URL` 指定其他服务地址。测试覆盖指针种植、升级、暂停、退款、首关正常布阵获胜、新卡解锁、各类武器效果、治疗、自动收阳光、割草机、失败重试、全关卡波次终结、首领出场、存档恢复和移动布局。全关卡流程测试会主动清除敌人以验证关卡状态机，不代表所有阵容都能通关。截图保存到忽略提交的 `test-results/`。
